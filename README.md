# TRAZA · Traza tu Guayaquil

Prototipo funcional de la app turística **TRAZA by ZEROS3 Travel Company**, proyecto de titulación (UNEMI).

App web para celular, en español e inglés: mapa ilustrado a escala del centro de Guayaquil, "Traza tu camino" con rutas a pie, fichas con historia en audio, pasaporte de sellos y recuerdos.

**Ver la app:** se publica con GitHub Pages desde la rama `main`.

Abre el enlace en el celular y usa "Agregar a pantalla de inicio" para usarla como app.
